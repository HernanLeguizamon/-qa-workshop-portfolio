# Product Overview 

## Nombre del producto 
PetStore Corp

## ¿Qué tipo de producto es? 
Plataforma de comercio electrónico (E-commerce) B2C con una aplicación web frontend y un servicio web de API REST para la gestión de inventario, pedidos y mascotas.

## ¿Qué problema resuelve? 
Satisface la necesidad de los dueños de mascotas de adquirir animales, alimentos, productos de cuidado y accesorios de forma remota y rápida, sin necesidad de desplazarse a una tienda física, permitiéndoles gestionar sus compras online las 24 horas del día.

## ¿Cómo genera valor para el negocio? 
1. Aumento de ventas: Amplía el alcance geográfico de la empresa al operar como un canal digital accesible desde cualquier lugar.

2. Automatización de procesos: Reduce la carga de trabajo manual al gestionar el inventario, los pedidos y las transacciones mediante un sistema centralizado.

3. Disponibilidad continua: Mantiene el negocio operativo las 24 horas del día, los 7 días de la semana, mejorando la captación de clientes.


## Usuarios principales - [Usuario 1] - [Usuario 2] - [Usuario 3] 
1. Cliente / Comprador online: Explora el catálogo, selecciona productos o mascotas, realiza compras y realiza el seguimiento de sus pedidos.

2. Administrador de Tienda / Gestor de Inventario: Gestiona el catálogo de productos, actualiza el stock disponible de mascotas y accesorios, y procesa las órdenes recibidas.

3. Desarrollador / Integrador de Sistemas (API): Utiliza los endpoints de la API pública para conectar servicios externos, automatizar actualizaciones de stock o sincronizar sistemas de logística.


## Funcionalidades principales - [Funcionalidad 1] - [Funcionalidad 2] - [Funcionalidad 3]
1. Navegación y búsqueda en el catálogo: Exploración de categorías (perros, gatos, peces, reptiles, aves) y visualización detallada de artículos y mascotas disponibles.

2. Gestión del carrito de compras y checkout: Adición de productos al carrito, cálculo de costos y procesamiento del formulario de orden/pago.

3. Gestión de inventario y pedidos vía API REST: Endpoints para consultar, agregar, actualizar y eliminar datos de mascotas (/pet), pedidos (/store/order) y usuarios (/user).
